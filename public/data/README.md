# 合成教學資料

本資料夾內所有內容都是為 HR × AI 教學網站建立的虛構資料，不代表真實員工、組織或學術證據。

## synthetic-employee-survey.csv

18 筆合成量化資料，欄位使用 1–5 分量尺，可用於：

- 描述統計
- 相關與視覺化練習
- 檢查 AI 是否過度解釋小樣本

## synthetic-comments.json

18 段虛構員工意見，可用於：

- 主題編碼
- 代表句與反例
- 匿名資料分析 Prompt

## simulated-literature.json

8 筆完全虛構的文獻紀錄，其中兩筆刻意加入明顯風險訊號。

用途是練習：

- 不因格式完整就相信引用
- 檢查作者、年份、期刊、研究方法與識別碼
- 區分「搜尋線索」和「已核對證據」

**這些文獻不得作為真實引用。**
